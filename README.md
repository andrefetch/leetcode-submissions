# LeetCode

My solutions to LeetCode problems for practice and interview prep.

## Structure

Solutions are grouped by type, so each folder holds problems that share an approach or pattern.

```
.
├── arrays/
├── two-pointers/
├── stacks/
└── ...
```

Files are named by problem number and title, like `217_contains_duplicate.py`.

## Format

Most solutions include a short note on the approach, time and space complexity, and the final accepted code.

```python
# 0001. Two Sum
# Approach: hash map of value -> index, single pass
# Time: O(n) | Space: O(n)
```

## Language

Primarily Python 3.
